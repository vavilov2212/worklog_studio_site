# Worklog Studio Landing Page — Developer's Project Summary

Reference doc for maintaining context across development sessions. Generated by mapping the codebase to the user-facing landing page.

## 1. Architecture & Tech Stack

- **Framework**: Next.js `^15.4.9` (App Router), React `^19.2.1` / React DOM `^19.2.1`, TypeScript `5.9.3` (strict mode).
- **Styling**: Tailwind CSS `4.1.11` via `@tailwindcss/postcss` (CSS-first config using `@theme` in [app/globals.css](app/globals.css), no `tailwind.config.js`). `tailwind-merge` + `clsx` combined in [lib/utils.ts](lib/utils.ts) (`cn()` helper). `tw-animate-css` and `@tailwindcss/typography` present as devDependencies but not visibly used yet.
- **Animation**: `motion` (Framer Motion successor, imported as `motion/react`) drives all scroll/mount transitions.
- **Icons**: `lucide-react`.
- **Other deps**: `@google/genai`, `@hookform/resolvers`, `class-variance-authority`, `firebase-tools` (devDependency) — present in `package.json` but **not referenced anywhere in the current component tree**; likely leftovers from the original AI Studio scaffold ([README.md](README.md) confirms this project was bootstrapped from a Google AI Studio template, hence `metadata.json` and `.env.example` referencing `GEMINI_API_KEY`/`APP_URL`, which are unused by this static landing page).
- **Deployment**: [.github/workflows/nextjs.yml](.github/workflows/nextjs.yml) — GitHub Actions workflow deploys to GitHub Pages on push to `main`, via `actions/configure-pages` (`static_site_generator: next`) → `next build` → `actions/upload-pages-artifact` pointing at `./out`.
  - ⚠️ **Known mismatch**: [next.config.ts](next.config.ts) sets `output: 'standalone'`, but the GH Pages workflow expects a static export at `./out` (which requires `output: 'export'`). As currently configured, `next build` will not produce an `./out` directory, so the deploy step would likely fail or deploy a stale/empty artifact. Worth verifying/fixing before next deploy.
  - The hardcoded icon path `/worklog_studio_site/icon.svg` in [app/layout.tsx](app/layout.tsx) implies an expected `basePath: '/worklog_studio_site'`, but no `basePath` is set in `next.config.ts` — `configure-pages` can inject this automatically for static export, but only takes effect if `output: 'export'` is actually used.
- **next.config.ts** also: disables ESLint during builds (`eslint.ignoreDuringBuilds: true`), allows `picsum.photos` as a remote image host (used for feature placeholder visuals), and disables HMR file watching when `DISABLE_HMR=true` (AI Studio agent-edit flicker workaround).

## 4. State, Data & Configuration

- **Feature copy/icons**: hardcoded array in [lib/config.ts](lib/config.ts) (`siteConfig.features`) — id/title/description/icon name/placeholder image URL (picsum.photos). Edit this file to change Features section copy.
- **Roadmap items**: hardcoded inline array in [Roadmap.tsx](components/Roadmap.tsx) (`items`) — not extracted to `lib/config.ts`.
- **Use case cards**: hardcoded inline array in [UseCases.tsx](components/UseCases.tsx) (`cases`).
- **Mock dashboard data**: hardcoded inline in [FeatureVisual.tsx](components/FeatureVisual.tsx) (`historyItems`, bar chart heights, stat cards, integration list).
- **Shared timer state**: [TimerContext.tsx](components/TimerContext.tsx) — `TimerProvider` wraps the whole app in `layout.tsx`; starts at a random time on mount (avoids hydration mismatch), ticks every second while running, resets to 0 on stop. Purely cosmetic/demo — no persistence.
- **App version badge**: fetched client-side at runtime from `https://api.github.com/repos/vavilov2212/worklog_studio/releases/latest` in `Hero.tsx`, falls back to `'v1.2'` on failure.
- **Download links**: hardcoded GitHub release URL pattern `.../releases/latest/download/worklogStudio.dmg`, repeated in Header, Hero, and Download components.
- **Theming**: color tokens defined once via Tailwind v4 `@theme` block in [app/globals.css](app/globals.css) (`--color-bg`, `--color-accent`, `--color-ink`, etc.) — accent blue is `#2563EB`.
- **Images/assets**: no local feature screenshots — Features section visuals are live React mockups ([FeatureVisual.tsx](components/FeatureVisual.tsx)), not static images. Only real binary assets are [app/icon.svg](app/icon.svg) and [public/static/app_icon_256.png](public/static/app_icon_256.png). Remote images allowed only from `picsum.photos` (placeholder use only, not currently rendered as `<Image>` anywhere visible).
