## If Something Goes Wrong

If the app crashes or behaves unexpectedly, report it on GitHub Issues at github.com/vavilov2212/wl-studio/issues, or email the author directly at vavilov2212@gmail.com. Include your OS and version, and steps to reproduce if possible.

If your tracked data looks wrong or missing, Worklog Studio automatically keeps timestamped local backup snapshots of its SQLite database file alongside the live one — check for a recent backup before assuming data is permanently lost.
