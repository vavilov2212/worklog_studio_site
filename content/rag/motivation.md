## Why Worklog Studio Was Built

Worklog Studio was built out of personal frustration with existing time-tracking tools, not as a market-research exercise. The author tried several tools first: Top Tracker (by Toptal), My Hours, RescueTime, and Clockspot.

Top Tracker came closest — it has a floating always-on-top window and hotkey-driven task switching, which the author found genuinely useful for staying in flow without alt-tabbing to a separate app. But it has no way to attach a description or comment to a task, which matters a lot for a workflow built around switching between different stages or objectives within the same task.

My Hours covers the comment/description gap that Top Tracker misses, but lacks the floating-window/hotkey workflow. Its free tier also doesn't allow editing existing entries. RescueTime and Clockspot are paid, aimed more at company/team time tracking, and RescueTime's timer-based workflow wasn't clear or central to the product.

More broadly, the tools the author evaluated were either subscription-only from day one, feature-heavy with invoicing/team/paywall functionality the author didn't need, or stored data on a remote server when local-first storage (with optional sync to something like Google Drive) would be preferable for a personal tool. Open-source alternatives existed too, but were similarly cluttered for a single-person, personal-use case.

Worklog Studio is the author's attempt at the tool that was missing: simple, free, local-first, and focused on frictionless single-keystroke tracking with per-task comments — without invoicing, team management, or paywalled core features.
