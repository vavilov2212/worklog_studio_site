## Exploratory Ideas (Not on the Committed Roadmap)

These are ideas the author is considering, not committed features — they should not be presented as "coming soon" or planned with any timeline. For committed plans, see the roadmap content instead.

- **Floating always-on-top window with hotkey task switching**: inspired by Top Tracker, lets a user switch tasks without leaving their current app. Not yet implemented.
- **Integrations with Notion, Jira, and Slack**: parsing tasks from those tools automatically instead of manual entry. Not yet started — only GitHub and Linear integrations are currently shipped.
- **AI-assisted nudges**: the app noticing context (e.g. switching from an IDE to a browser) and proactively asking things like "are you still working on this?" or suggesting a description update. Purely an idea at this stage.
- **Cloud/SaaS web version**: a web-based version with sign-in and remote data storage, as an alternative to today's fully local-first desktop app. Just a loose idea, not scoped or scheduled.
