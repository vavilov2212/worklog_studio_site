## How Worklog Studio Compares

Worklog Studio was built after using and evaluating several other time trackers, each missing something:

- **Top Tracker (Toptal)**: has a floating always-on-top window and hotkey task switching, but no way to add comments or descriptions to a task.
- **My Hours**: supports task descriptions, but the free tier doesn't allow editing entries, and it has no desktop app (browser/PWA only).
- **RescueTime**: fully paid, oriented around passive activity tracking rather than an explicit start/stop timer workflow.
- **Clockspot**: fully paid, built for company employee time tracking with manual entry, web-only.

Worklog Studio's current differentiators are: free to use, local-first storage (no account, no server-side data), per-task and per-entry comments/descriptions, and a single-keystroke start with no mandatory project setup. It does not currently have Top Tracker's floating-window/hotkey workflow — that's a future idea, not a shipped feature (see the future-ideas content). It also deliberately leaves out invoicing, billable rates, and team/client management, which the tools above are partly built around.
